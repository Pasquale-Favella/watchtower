# Deliver side chat bring-back with the main chat's next Run

A side chat stays a separate linked Task with its own Conversation, but it shares its parent's checkout, is hidden from Task listings, and is opened from the parent's right panel. Bring back does not append text to the main draft. It records one pending transfer on the parent Conversation, which the parent's next Run consumes exactly once, under the current owner epoch. The transfer is bounded at 131,072 characters, the same limit ADR 0042 applies to handoff context. Bring back is refused while the main Conversation has an active or queued Run, so a transfer never races a Run that already started. A second bring-back from the same side chat supersedes the first; one from another side chat waits until the pending transfer is delivered. A launch failure before the driver starts returns the consumed transfer to pending. A Run that reached the driver does not, so its context is never delivered twice.
